# CS-350-Emerging-Systems-Architecture
MY final class that Combines physical hardware and coding using PYTHON


For this project, I worked with a Raspberry Pi, a breadboard, GPIO pins, and red and blue LEDs. The goal was to learn how to connect hardware and control it using Python code. I had to make sure the wiring was correct, use resistors, and connect everything properly. This project helped me understand how code can interact with physical components and how important it is to check both the hardware and software when something does not work.

I think I did well with troubleshooting and sticking with the project when I ran into problems. I tested individual components to narrow down what was causing the issues instead of trying to fix everything at once. For example, testing the red LED separately helped me confirm that the wiring and GPIO connection were working. I learned that taking things one step at a time makes troubleshooting easier and helps me understand what is actually going wrong.

I could improve by getting better at identifying problems more quickly. At times, it was difficult to tell whether an issue was coming from the wiring, GPIO settings, or Python code. I want to get more comfortable reading circuit diagrams and checking connections before running my programs. With more practice, I think I will be able to recognize common problems faster and spend less time troubleshooting.

I am adding Raspberry Pi documentation, Python resources, and GPIO guides to my support network. I also plan to keep using the Linux terminal and small test programs to check whether individual components are working correctly. When I run into something I do not understand, I can refer to course materials, ask my instructor questions, or look for help in programming communities.

The skills I learned from this project that I can use in future coursework include troubleshooting, problem-solving, Python programming, and working with hardware. I learned how to break a problem into smaller parts and test each part individually. These skills will be useful in future Raspberry Pi and embedded systems projects, especially when working with sensors or other physical components.

I made the project easier to maintain and modify by testing individual components and keeping the code organized. Using smaller test programs helped me figure out whether the hardware was working before moving on to the larger program. Keeping the code readable also makes it easier to find mistakes and make changes later. In the future, I want to keep improving how I organize and document my code so that troubleshooting and adding new features become easier.
